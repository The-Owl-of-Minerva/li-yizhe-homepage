# First Note: Blog Framework Example

This is a **Markdown-driven** post template.

For each future essay, you only need to:

1. add a new `.md` file inside `posts/`;
2. register its title, date, summary, and file path in `posts/posts.json`;
3. run `git add .`, `git commit`, and `git push`;
4. let Vercel redeploy automatically.

## What can go here

Research reflections, reading notes, observations about cities, technical notes, or longer personal essays all fit naturally here.

> This entry is only a framework. Replace or delete it once the first real post is ready.
